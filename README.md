# Cursos de OlgaDev

Este repositorio guarda el material público del curso **«IA y creación de
aplicaciones para emprendedores y autónomos»**, de **Olga Angélica Ortiz**
(marca [OlgaDev.com](https://olgadev.com)).

## Para quién es esto

Para cualquier persona del curso, o cualquier curiosa que llegue desde
[olgadev.com](https://olgadev.com), que quiera:

- Revisar el código de las apps de cada clase (son HTML autocontenido, sin
  build ni dependencias — se abren con hacer doble clic).
- Descargar las plantillas y matrices de trabajo.
- Reutilizar el material en su propio negocio, dentro de las licencias de
  abajo.

## Cómo está organizado

```
modulo-1-fundamentos/
  clase-01-nuevo-mapa-de-la-ia/
  clase-04-marco-legal-y-etico/
modulo-2-voice-dna/
modulo-3-automatizaciones-sin-codigo/
modulo-4-apps-con-ia/
modulo-5-monetizacion/
```

Cada clase con material listo tiene su propia carpeta con un `README.md`
que explica el objetivo, la actividad y cómo abrir lo que haya (una app,
una demo, una plantilla). Los módulos y clases que todavía no tienen
material publicado dicen **«en preparación»** — este repositorio crece
clase a clase, no de golpe.

## Construir en público

Este curso no es teoría separada de la práctica: enseña el trabajo real
de Olga, día a día, usando Claude como mano derecha y otras IA como
herramientas. Cuando una clase muestra una pieza de ese trabajo (un mapa,
una demo, un flujo), está tomada en **modo demo** — nunca con datos reales
de un cliente ni credenciales verdaderas.

## Cómo pedir el material completo

El material vivo (PDFs por clase, plantillas, diplomas) se entrega hablando
con **Ada**, la asistente del curso, desde [olgadev.com](https://olgadev.com).
Este repositorio es el respaldo público y técnico de esa entrega, no la
sustituye.
